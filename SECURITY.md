# Security

Dieses öffentliche Repository darf keine Live-Zugangsdaten oder privaten ECHO-Spielstände enthalten.

Falls versehentlich ein Secret, eine Google-Datei-ID oder ein privater Spielzustand committed wurde, sollte der Wert zuerst in der Quellplattform widerrufen bzw. ersetzt und anschließend aus der Git-Historie entfernt werden. Ein einfaches Löschen in einem späteren Commit reicht für echte Secrets nicht aus.
